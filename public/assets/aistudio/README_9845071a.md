# DUO LUDO v1.0.1

A self-contained two-player board game with local Humo (human vs human) and Robo (human vs computer) modes. The standalone HTML build can be opened directly in a modern browser without a server or internet connection.

## Run the game
1. Extract this ZIP.
2. Open `dist/duo-ludo.html` in Chrome, Edge, Firefox or Safari.
3. To edit the project, open `index.html` or serve the project folder with a local static web server.

## Final refinements
- Three maps: Orbit (true circle), Citadel (true square) and Infinity (two equal circular loops). Crossroads and Clover are removed.
- Every token starts on its own home-lane gate, completes the full outer route and returns to that same gate before entering the home lane.
- The entry rule is configurable in Application Settings: require a 1, or allow any dice number to open a token.
- Classic Dice keeps equal 1-in-6 probabilities. Modern Dice uses the disclosed adaptive probability system and a player-coloured die, so the visual and probability differences are visible during play.
- Humo (human vs human) and Robo (human vs computer) modes remain available. Default names are Humo and Humo for local two-player, or Humo and Robo for Robo mode; names can be edited.
- Default player colours remain blue and pink. Playground Appearance in Application Settings offers exactly three alternatives: teal, orange and violet, plus four board themes and global application themes.
- The welcome screen uses a redesigned inline SVG Duo Ludo icon and wordmark; the large splash artwork has been removed. The splash fades in without sliding upward.
- One combined How to Play and Quick Guide entry point replaces the duplicate help icons.
- No saved-match/resume feature is provided. Exiting to the setup screen or closing the browser does not save an in-progress match. Match history and application preferences remain local.
- Dice does not travel between player sides and has no pulsing dock border; it snaps to the active player's dock. Classic and Modern dice also have distinct face styling.
- Responsive square board, boundary-attached token docks, local Humo undo, move history, interactive guide, Humo device handover, achievements, history and accessibility improvements.

## Rules
- By default, a token requires a 1 to leave base; this can be turned off in Application Settings.
- Entering places the token on its start gate. The token must complete the full outer loop and return to that same gate before moving into its home lane.
- A 6, a capture or reaching home grants an extra turn.
- Home requires an exact roll.
- Star tiles are safe; bolt tiles give a +3 boost when the route allows it.
- Two tokens on the same tile protect one another.
- Classic Dice has equal odds for all six faces. Modern Dice adapts probabilities based on match conditions; Dice Insight shows the normalized odds used for a roll.

## Project structure
- `index.html`, `css/`, `js/`: editable application source; the current brand icon is inline SVG.
- `dist/duo-ludo.html`: generated standalone browser build with all styles and scripts embedded.
- `tools/build.py`: rebuild the standalone file (`python3 tools/build.py`).
- `tests/engine.test.js`: geometry, full-lap rules, entry setting, dice, RNG and match-simulation tests (`node tests/engine.test.js`).

## Local data
Match history and application preferences are stored locally in the browser. In-progress matches are not saved and cannot be resumed. Online multiplayer, cloud sync and server-backed leaderboards are not included.
